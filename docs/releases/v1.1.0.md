# Wi-Fi Monitor 1.1.0

Installation and updates were made more reliable, and English and Russian documentation and interface support were added.

## Fixed

- Fixed one-line updates that silently reused old files from the current directory.
- Added staging of all replacement files and backups before any installed file is changed.
- Added automatic restoration after file replacement or RPC registration failures, with explicit reporting if restoration cannot complete.
- Fixed failed installer downloads being reported as successful by the installation command.
- Pinned downloaded component files to the installer's matching release tag.
- Corrected the LuCI dependency check for OpenWrt 24.10 and added a check for RPC registration after installation.

## Added

- Added English and Russian interface support, including labels, durations, dates and band filters.
- Added English documentation with a separate linked Russian README.
- Added the MIT License and English interface screenshots.
- Added regression tests for stale source directories, staging and replacement failures, failed initial installation, and failed downloads.

## Validation

- JavaScript syntax and English/Russian interface tests passed.
- Installation, backup, removal and failure-recovery tests passed in isolated OpenWrt 24.10.1 directories.

Existing installations can be updated using the command in the [installation guide](https://github.com/numbereleven-a/OpenWrt-WiFi-Monitor#installation). No router reboot is required. Existing files are backed up before replacement; the original command-line `wifi_monitor` is preserved.
